# 项目规则（供 Qoder Agent 遵循）

## 项目定位
「知库」是一个面向学习、科研与工作场景的个人知识检索工具，核心检索能力由
**OceanBase seekdb**（嵌入式本地库，高层 SDK `pyseekdb`）提供。

## 硬性约束
- 检索引擎只能通过 `src/repository.py` 这一层访问 seekdb，业务代码不直接拼底层驱动。
- 向量由 `src/embedder.py` 生成；默认使用内置离线向量器，保持零外部依赖。
  若替换为真实 embedding 模型，必须保证维度与建库维度（默认 256）一致。
- 元数据仅存标量；多值字段（tags）用逗号拼接成字符串存储。
- 不引入需要公网鉴权的第三方服务作为运行必需依赖；可选的 FastAPI 演示服务除外。
- 代码注释用中文，命名清晰，便于评审看懂 seekdb 的接入点。

## 检索口径
- `vector`：HNSW 余弦最近邻；ANN 索引未就绪召回为空时，回退全量向量余弦精排兜底。
- `fulltext`：文档包含匹配（标题并入文档字段一起索引）。
- `hybrid`：全文支路 + 向量支路，RRF 倒数排名融合。
- 写入后向量索引异步构建；等待 1–2 秒近似召回更准，兜底逻辑保证空索引期也有结果。

## 目录约定
- `src/`：应用源码；`scripts/`：自测与导入脚本；`data/`：样例数据；`site/`：Qoder Sites 静态演示站素材。
