解决的问题

  • 整理文献要翻几十篇论文，找不到相关段落和出处；
  • 复习时翻不到上学期的笔记，知识点散落各处；
  • 周报、纪要要从聊天记录里一条条拼，重复又耗时。

核心功能

条目管理

新增 / 批量导入 / 列表 / 按类别过滤 / 删除，笔记、论文、纪要统一入库。

关键词全文检索

标题、正文、标签一起索引，按关键词包含匹配，擅长精确术语召回。

语义向量检索

文本向量化后走 HNSW 余弦近邻，意思相近也能召回，不依赖用词完全一致。

混合检索（RRF）

全文支路 + 向量支路并行，倒数排名融合重排，兼顾精确命中与语义近义。
