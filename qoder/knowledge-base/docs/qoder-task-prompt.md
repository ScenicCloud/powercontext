# 可直接粘贴进 Qoder 的任务提示词

## 一、后端项目（在 Qoder 工作区中打开本目录后使用）

```
请在当前目录下协作完善这个「个人知识检索助手」项目，要求如下：

1. 场景：面向学习、科研、工作提效，管理课程笔记、文献摘要、周报、会议纪要等条目。
2. 检索引擎必须真实接入 OceanBase seekdb（高层 SDK pyseekdb，嵌入式本地库），检索能力集中在 src/repository.py：
   - upsert/bulk_upsert 写入文档、向量与元数据；
   - 向量检索：HNSW + 余弦最近邻；
   - 全文检索：文档包含匹配；
   - 混合检索：全文支路 + 向量支路，用 RRF 倒数排名融合；
   - 支持按类别（study/research/work/general）元数据过滤、列表、删除、计数。
3. 向量由 src/embedder.py 生成，默认使用内置离线向量器，保持零外部依赖；维度与建库维度一致（256）。
4. 提供命令行 src/cli.py：ingest 导入样例、list、search（hybrid/vector/fulltext）、add、count、delete。
5. data/sample_notes.json 提供三类样例数据；scripts/selftest.py 覆盖写入、全文、向量、混合、过滤、删除断言。
6. 遵循 .qoder/rules/project-rules.md 中的约束；中文注释，命名清晰。
7. 完成后运行 python scripts/selftest.py，确保全部断言通过；如失败请定位并修复，不要跳过断言。

请先阅读 README.md 与 src/ 下现有代码，再做必要的补充与修正。
```

## 二、Qoder Sites 演示站（Sites 新任务、带 @sites 时使用）

```
@sites 帮我生成一个「个人知识检索助手」静态演示站，要求：

- 主题：基于 OceanBase seekdb 的学习/科研/工作资料检索工具的作品展示页。
- 页面包含：标题与一句话介绍；检索引擎（seekdb）、开发工具（Qoder）、发布渠道（Qoder Sites）等标签；「解决的问题」痛点列表；「核心功能」卡片；一个搜索框；类别下拉（全部/学习/科研/工作）；检索模式切换（混合检索/仅关键词/仅语义近邻）；结果卡片展示标题、类别、正文、标签、日期；演示截图/录屏占位区；代码仓库链接按钮；使用效果数据占位区（人数/次数/提效对比）。
- 内置 7 条样例笔记（学习 3 条、科研 2 条、工作 2 条），数据见 site/index.html 内的 NOTES 数组，保持一致。
- 前端演示逻辑：关键词子串匹配 + 词项重合度打分；混合模式取两者加权；按分数排序；类别过滤。
- 风格：浅色背景、白色圆角卡片、克制的品牌蓝点缀，桌面与移动端响应式；单文件、无外部依赖。
- 先出预览，不要直接发布；我确认交互无误后再 Publish。
- 页面注明：真实向量/全文/混合检索由仓库内 Python 应用调用 seekdb 完成，本站为内置样例的静态演示。
```
